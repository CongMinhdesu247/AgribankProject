# Agribank Helpdesk UI

## Deploying to Render

This repository contains a Render Blueprint at `../render.yaml`. It creates two
free web services in Singapore:

- `agribank-api`: the Node.js API in this directory's sibling folder
  `agribankservicecv`.
- `agribank-ui`: this React app served by Caddy. Caddy forwards `/api/*` to the
  API's public HTTPS URL, so the browser uses one origin. Render free web
  services cannot receive private-network traffic.

### Before creating the Blueprint

1. Push the repository, including `render.yaml`, to GitHub or another Git
   provider connected to Render.
2. Ensure a reachable MySQL 8 database is available. Render's Blueprint here
   does not create or migrate a database. The database can remain with a
   provider that allows external connections, or use a MySQL service with
   persistent storage. Render's MySQL instructions require a persistent disk;
   free web services cannot store a MySQL database persistently.
3. Back up the current database and import it into the destination MySQL before
   switching the app. Preserve the existing schema and data; the API expects
   the `users`, `tickets`, `categories`, `sla_configs`, and related tables.
   Apply any migrations that have not already been run, in order.

### Create the services

1. In Render, choose **New > Blueprint** and connect the repository/branch.
2. Review the two services and provide the prompted secret values for the API:
   - `IT_REGISTRATION_CODE`: private code for registering IT staff.
   - `DB_HOST`, `DB_NAME`, `DB_USER`, and `DB_PASSWORD`: destination MySQL
     connection details. Keep port `3306` unless the provider specifies another
     port (then edit `DB_PORT` in the API service settings).
3. For `API_UPSTREAM`, enter the API's public Render URL with `https://`, for
   example `https://agribank-api.onrender.com`. If Render assigns a different
   URL, update `API_UPSTREAM` in the UI service settings after creation.
4. Deploy the Blueprint. `SESSION_SECRET` is generated by Render.
5. Wait until `agribank-api` and `agribank-ui` are live. Open the UI's `onrender.com`
   URL and check sign-in and ticket operations before changing any existing
   domain or shutting down the old deployment.

The API's `/health` endpoint checks its MySQL connection. A database that is
unreachable or missing required tables will keep the API unhealthy. Do not put
database passwords or bot tokens in this repository.

Render's free web services sleep after 15 minutes without traffic and can take
about a minute to wake up. Free web service storage is ephemeral, so the
database must use persistent storage elsewhere. Render's free Postgres expires
after 30 days and is not a drop-in replacement for this MySQL application.

### Local development

The Vite app calls `http://localhost:5000/api` by default. Start the Node API
from `agribankservicecv` with `npm run dev`, then start Vite from this directory
with `npm run dev`.

The separate Spring Boot project in `agribankservicecv` is not called by this
UI's current API client and is not included in this Render Blueprint.
